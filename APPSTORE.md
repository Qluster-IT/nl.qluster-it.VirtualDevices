# Virtual Devices

This app gives you the opportunity to add Virtual Devices to Homey. You can operate the Virtual Devices from the UI and/or use them in flows.

Or you can add a mode and add it as a condition, e.g. to disable multiple flows when going on Holiday.

## More information:

For setup instructions and how-to guides, see the [Virtual Devices Wiki](https://github.com/Qluster-IT/nl.qluster-it.VirtualDevices/wiki).
The [current source repository](https://github.com/Qluster-IT/nl.qluster-it.VirtualDevices) contains the app code.
